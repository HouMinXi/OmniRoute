- **Security (GHSA-7j4q-6gx6-pg77):** an API key restricted to specific combos (`allowedCombos`) could still dispatch the built-in virtual routes `auto/*` and `qtSd/*` — they are not persisted combo rows, so the allow-list lookup treated them as "not a combo" and let them through, reaching every connected provider (including OAuth subscription accounts). Virtual routes are now matched against the combo allow-list like any combo: denied unless the key allows all combos (`combo/*`) or lists the route; `allowAutoCombos: false` still applies on top. Reported and fixed by @aldoeliacim.
