- **Security (GHSA-jmq6-8j86-8xqj):** the provider connection test (`POST /api/providers/{id}/test`, and the same test run by `test-batch` and by `POST /api/providers` for a new connection) could spawn `sh -c 'command -v …'` on the host to check the local `cline` / `qoder` CLI, although those routes are reachable remotely.
