- **fix(relay):** the relay's per-(token, client) throttle now keys on the client address the authz pipeline resolves at the trust boundary — the connection's peer, or the client a loopback / private-network / Cloudflare / `OMNIROUTE_TRUSTED_PROXIES` proxy reported — forwarded to the route as a stamped header the pipeline strips from client input. Before, it keyed on `X-Forwarded-For` / `X-Real-IP` as sent, so a direct caller could reset the bucket by rotating the header (the per-token limit still applied). Clients behind the same reverse proxy keep separate buckets; when no stamp exists every caller of a token shares one bucket and the forwarding headers remain log-only.
