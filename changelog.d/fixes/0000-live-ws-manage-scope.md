- **fix(ws):** the live dashboard WebSocket sidecar now accepts a Bearer API key only when it holds a management scope (`manage`/`admin`); inference-only keys are refused with the existing `UNAUTHORIZED` close while dashboard sessions and the env master key are unchanged. Its internal event endpoint (`POST /__omniroute_event`) also stops trusting a loopback peer that arrives with proxy-hop headers (`x-forwarded-*`, `x-real-ip`, `forwarded`, `via`), so a same-host reverse proxy can no longer relay fabricated dashboard events; the in-process publisher is unaffected.
