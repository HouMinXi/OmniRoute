- **fix(command-code):** stop rewriting `reasoning_effort` `xhigh` to `max`. Command Code's own validator advertises `low|medium|high|xhigh|max`, so `xhigh` is a native and distinct tier there, and the provider-wide rule silently spent a different reasoning level than the caller asked for. It also overwrote the nested `reasoning.effort` carrier that the Responses path reads. The model-level ceilings are untouched: GLM 5.1+, DeepSeek V4+ and Kimi K3+ still map `xhigh` to `max`, as do the Ollama Cloud and OpenCode Go gateways, and OpenRouter still passes `xhigh` through unchanged.
