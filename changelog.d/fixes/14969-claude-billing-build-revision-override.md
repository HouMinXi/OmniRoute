- **fix(claude):** make the `cc_version=` build revision overridable. `CLAUDE_CODE_CLIENT_VERSION` could already be overridden to clear Anthropic's model gate, but the 3-character revision suffix stayed pinned, so overriding the version alone advertised a `version.revision` pair no real Claude Code binary emits (e.g. `2.1.283.1e2`). `CLAUDE_CODE_CLIENT_BUILD_REVISION` now overrides it, and every wire consumer reads it live alongside the version. Documented in `.env.example` and `docs/reference/ENVIRONMENT.md`.
