- **fix(authz):** relay token management (`GET`/`POST /api/relay/tokens`, `GET`/`PATCH`/`DELETE /api/relay/tokens/{id}`) now requires a dashboard session or a manage-scoped API key even when the dashboard runs with login disabled — relay tokens are reusable inference credentials, so minting, listing, editing and revoking them joins the always-protected tier alongside the other credential-issuing routes. Automation that already sends a manage key is unaffected.
