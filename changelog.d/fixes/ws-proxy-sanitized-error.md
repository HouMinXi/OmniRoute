- **Security (Hard Rule #12):** the Responses WebSocket proxy (`dist/responses-ws-proxy.mjs`, shipped with the standalone server) sent raw exception text to the client in two places — the 500 body of a failed upgrade and the `response.failed` frame when the upstream connection failed. The latter could carry the configured upstream proxy URL including its credentials. Both now return a fixed message; the detail stays in the server log / request history. Flagged by CodeQL (`js/stack-trace-exposure`, `js/xss-through-exception`).
