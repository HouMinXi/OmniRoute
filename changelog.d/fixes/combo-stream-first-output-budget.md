- **fix(combo):** a streaming target that opens the response and then produces nothing no longer holds the whole combo. The per-target budget now bounds the time to the first output frame instead of the time to response headers, so a silent upstream is abandoned and the combo falls over to its next model; token generation that has started still streams to completion untouched. Output is judged with the same predicate TTFT uses, so this gateway's own keepalive frames (`response.in_progress`, `event: progress`) never count as an answer. Note for operators: the default 120s budget now also caps time-to-first-token on streaming combos — raise `targetTimeoutMs` for slow reasoning pools.
