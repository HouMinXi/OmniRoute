> مفاتيح تبديل وقت التشغيل التي تغيّر سلوك OmniRoute **من دون إعادة النشر**.
> كل علامة مدرجة هنا معرّفة في
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — وهو المصدر الوحيد للحقيقة. تقرأ كلٌّ من لوحة المعلومات وواجهة REST API من
> ذلك الملف، ولذلك يُنشأ الجدول أدناه ليطابقه بنسبة 1:1.

---

## ما هي علامات الميزات

علامة الميزة هي مفتاح تبديل مُسمّى (قيمة منطقية أو تعداد) يمكن تغيير قيمته في
وقت التشغيل وحفظها في قاعدة البيانات، من دون الحاجة إلى إعادة نشر العملية. تُوصَف كل
علامة بواسطة `FeatureFlagDefinition` يتضمن `key` و`label`
و`description` و`category` و`defaultValue` و`type` وتلميح `requiresRestart`.

### ترتيب تحديد القيمة

تُحدَّد **القيمة الفعلية** للعلامة بواسطة
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) وفق
ترتيب الأولوية التالي (تفوز الأولوية الأعلى):

1. **تجاوز قاعدة البيانات** — قيمة مخزنة في جدول `key_value` ضمن نطاق الأسماء
   `feature_flags` (تُعيَّن عبر لوحة المعلومات أو واجهة REST API).
2. **متغير البيئة** — `process.env[<KEY>]`، إذا كان معيّنًا وغير فارغ.
3. **القيمة الافتراضية للتعريف** — قيمة `defaultValue` من `featureFlagDefinitions.ts`.

تُعد العلامة المنطقية **مفعّلة** عندما تكون قيمتها الفعلية `"true"` أو
`"1"` أو `"yes"` (راجع `isFeatureFlagEnabled()`).

> [!NOTE]
> لمعظم العلامات أيضًا متغير بيئة مطابق يحمل **الاسم نفسه**
> وموثّق في [`ENVIRONMENT.md`](./ENVIRONMENT.md). تكون الأولوية لتجاوز قاعدة البيانات الخاص بالعلامة
> على متغير البيئة هذا. تُحفَظ العلامة التي تحتوي على
> `requiresRestart: true` فورًا، لكنها لا تُقرأ مجددًا إلا عند بدء تشغيل العملية
> — ويؤدي تبديلها إلى إظهار لافتة **"إعادة تشغيل الخادم"** في لوحة المعلومات.

## دليل العلامات

86 علامة موزعة على 6 فئات. **الافتراضي** هو القيمة الافتراضية المحددة — وهي القيمة
المستخدمة عند عدم وجود تجاوز في قاعدة البيانات أو متغير بيئة.

## تبديل العلامات

### لوحة التحكم

انتقل إلى **لوحة التحكم → الإعدادات → علامات الميزات**
(`/dashboard/settings/feature-flags`). تدعم الشبكة
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ما يلي:

- **البحث** حسب المفتاح أو الوصف، و**التصفية** حسب الفئة (بالإضافة إلى عرض اصطناعي باسم
  **يتطلب إعادة التشغيل**).
- **مفتاح تبديل** للعلامات المنطقية و**قائمة منسدلة** لعلامات التعداد
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **شارة مصدر** لكل علامة — `DB` أو `ENV` أو `DEF` — توضّح مصدر
  القيمة الفعلية.
- زر **إعادة تعيين** (يظهر فقط للعلامات التي مصدرها `DB`) لإزالة التجاوز،
  وزر **إعادة تعيين جميع التجاوزات** في الأسفل.
- لافتة **إعادة تشغيل الخادم** عند تغيير علامة `requiresRestart`.

### واجهة REST API

تمر جميع العمليات عبر مسار واحد:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
تتطلب كل طريقة جلسة لوحة تحكم موثّقة (وإلا تُرجع `401`).

#### `GET /api/settings/feature-flags`

يعيد جميع العلامات مع قيمتها الفعلية ومصدرها وملخص عنها.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... جميع العلامات البالغ عددها 77
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

يضبط تجاوزًا واحدًا أو يزيله. النص: `{ key: string; value?: string }`.
يؤدي حذف `value` إلى إزالة التجاوز (واستعادة قيمة env / القيمة الافتراضية).

```bash
# تعيين تجاوز في DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# إزالة التجاوز (من دون "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

تكرر الاستجابة `effectiveValue`/`source` الجديدتين، و`previousValue`/
`previousSource`، و`requiresRestart`. تُرفض المفاتيح غير المعروفة وقيم التعداد
الخارجة عن النطاق مع `400`.

#### `DELETE /api/settings/feature-flags`

يمسح **جميع** تجاوزات DB دفعة واحدة، ويستعيد لكل علامة قيمة env / القيمة الافتراضية.
يعيد `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> لا تصبح العلامات التي تحتوي على `requiresRestart: true` سارية إلا بعد إعادة تحميل العملية.
> يستدعي تدفق إعادة التشغيل في لوحة التحكم `POST /api/restart`، ثم يستطلع
> `GET /api/health/ping` إلى أن يعود الخادم للعمل.

## البديل الاحتياطي الطارئ للميزانية

يتحكم `OMNIROUTE_EMERGENCY_FALLBACK` (الفئة `runtime`، والقيمة الافتراضية `true`) في
مسار البديل الاحتياطي المجاني للطوارئ في
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
عند تمكينه، تُوجَّه الطلبات التي تستنفد ميزانيتها إلى موفّر/نموذج احتياطي مجاني
بدلًا من فشلها نهائيًا. اضبطه على `false` (أو `0`) — عبر مفتاح التبديل في
لوحة المعلومات، أو قيمة متجاوزة في قاعدة البيانات، أو متغير البيئة
`OMNIROUTE_EMERGENCY_FALLBACK` — لتعطيل هذا السلوك والسماح بفشل الطلبات التي
استنفدت ميزانيتها. (أُتيح على هيئة مفتاح تبديل في لوحة المعلومات ضمن طلبي السحب #3741 / #3752.)

تتضمن الاستجابة المقدَّمة عبر هذا البديل الاحتياطي الترويسة
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`، بحيث يمكن
للعميل معرفة أن الطلب أُعيد توجيهه دون مقارنة `X-OmniRoute-Provider` في الاستجابة
مع طلبه. لا تظهر هذه الترويسة في أي استجابة أخرى.
