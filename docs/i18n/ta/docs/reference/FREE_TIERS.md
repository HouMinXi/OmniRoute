> **பயனர்களுக்கு**: எளிய வழிகாட்டியைத் தேடுகிறீர்களா? இலவச AI-ஐப் பெறுவதற்கான படிப்படியான வழிமுறைகளுக்கு [இலவச அடுக்குகள் வழிகாட்டி](../getting-started/FREE-TIERS-GUIDE.md)-ஐப் பார்க்கவும்.

> **கடைசியாக ஆய்வு செய்யப்பட்டது:** 2026-06-17 — ஒவ்வொரு வழங்குநருக்குமான இணைய ஆய்வு (அதிகாரப்பூர்வ ஆவணங்கள் + கடந்த 7 நாட்களின் செய்திகள், எதிர்மறைச் சரிபார்ப்புடன் கூடிய 50-agent ஆய்வு), ஒவ்வொரு இலவச அடுக்கின் ஒதுக்கீடு + ToS ஆகியவற்றைப் புதுப்பித்தது. **பகுதியளவு மறு-தணிக்கை 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — கீழேயுள்ள தேதியிட்ட குறிப்பைப் பார்க்கவும்).
> **உண்மைக்கான மூலாதாரம் (பட்டியல்):** `open-sse/config/freeModelCatalog.ts` (ஒவ்வொரு MODEL-க்குமான வரம்புகள், பகிரப்பட்ட தொகுப்புகள் நகல்நீக்கம் செய்யப்பட்டவை). கீழேயுள்ள token வரம்பு எண்கள் நேரடி இணைய ஆய்விலிருந்து பெறப்பட்டவை; அவை ஒரு **தோராய மதிப்பீடு** — [ஆய்வுமுறை மற்றும் எச்சரிக்கைகள்](#methodology--caveats)-ஐப் பார்க்கவும்.

## சுருக்கம் — OmniRoute உண்மையில் எவ்வளவு இலவச inference-ஐ ஒருங்கிணைக்கிறது?

இந்த எண்ணிக்கைகள், பட்டியல் முழுவதிலும் உள்ள தனித்தனி மூன்றாம் தரப்புக் கணக்குகளையும் தகுதி நிபந்தனைகளையும் விவரிக்கின்றன. OmniRoute இந்த வரம்பை வழங்குவதில்லை: தேவையான கணக்குகள் அல்லது நற்சான்றுகளை நீங்கள் பெற வேண்டும், தகுதியுள்ள வழங்குநர்களை இணைக்க வேண்டும், மேலும் அவர்களின் வரம்புகளுக்கு இணங்க வேண்டும். தகுதியுள்ள route எதுவும் இல்லாத புதிய நிறுவலில் பூஜ்ஜியம் உட்பட, உண்மையில் பயன்படுத்தக்கூடிய திறன் இதைவிடக் குறைவாக இருக்கலாம். `tos: avoid` எனக் குறிக்கப்பட்ட வழங்குநர்கள் இயல்பாகவே தானியங்கி routing-இலிருந்து விலக்கப்படுகிறார்கள்.

**2026-10-08 அன்று சரிபார்க்கப்பட்டது:** [Cerebras](https://www.cerebras.ai/pricing), கட்டண முறையொன்று தேவைப்படும், 30 நாட்களுக்குப் பிறகு காலாவதியாகும், ஒருமுறை மட்டுமே வழங்கப்படும் $5 விளம்பர credit-ஐ வழங்குகிறது. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits), project/model/tier வீத வரம்புகளை வெளியிடுகிறது; அளவிடப்பட்ட மாதாந்திர முக்கிய எண்ணிக்கையில் அது தொடர்ந்து சேர்க்கப்படவில்லை.

**நேர்மையான முக்கியக் கூற்று:** _OmniRoute, 34 இலவச அடுக்குத் தொகுப்புகளில் மாதத்திற்கு **~1.62B ஆவணப்படுத்தப்பட்ட இலவச token-களை** ஒருங்கிணைக்கிறது (பதிவுசெய்தல் credit-களுடன் உங்கள் முதல் மாதத்தில் ~2.22B வரை) — அத்துடன் நிரந்தரமாக இலவசமான, உச்சவரம்பில்லாத வழங்குநர்களின் நீண்ட பட்டியலும் உள்ளது — மேலும் RTK + Caveman compression (15–95% token சேமிப்பு) அதை இன்னும் அதிகமாக நீட்டிக்கிறது._

> **முந்தைய ~1.94B-இலிருந்து இது ஏன் குறைந்தது.** 2026-06-17 புதுப்பிப்பு என்பது இழப்பல்ல, நேர்மையான திருத்தம்: `gemini` இப்போது pool அடிப்படையில் நகல் நீக்கப்பட்டுள்ளது (முன்பு ஒவ்வொரு Flash மாறுபாட்டையும் தனித்தனியாகக் கணக்கிட்டதால் மிகைப்படுத்தப்பட்டது, 462M → 60M), `cloudflare-ai` அதன் உண்மையான நாளொன்றுக்கு 10k-Neurons அளவிற்குத் திருத்தப்பட்டது (122M → 30M), `doubao` மீண்டும் நிகழாத ஒருமுறை பதிவுசெய்தல் கிரெடிட்டாக மறுவகைப்படுத்தப்பட்டது, மேலும் நிறுத்தப்பட்ட அடுக்குகள் அகற்றப்பட்டன (`chutes`/`phind`/`kluster` நிறுத்தப்பட்டன). இது `llm7` (சரியான நாளொன்றுக்கு 5M → 150M) மற்றும் புதிய இலவச வழங்குநர்களால் (Kilo, OpenCode Zen, Z.AI GLM-Flash) ஓரளவு ஈடுசெய்யப்பட்டது.
>

OmniRoute, "இது இலவசமா?" என்ற கேள்விக்கு வேண்டுமென்றே வெவ்வேறு ஆதாரங்களைப் படிக்கும் இரண்டு செயல்முறைகள் மூலம் பதிலளிக்கிறது:

## வழிமுறையும் வரம்புகளும்

- எண்கள், **2026-06-17** நிலவரப்படி ஒவ்வொரு வழங்குநரும் ஆவணப்படுத்திய இலவச அடுக்கு வரம்புகளிலிருந்து வலை ஆய்வு மூலம் சேகரிக்கப்பட்ட **அதிகபட்ச மதிப்பீடுகள்**. இலவச அடுக்குகள் தொடர்ந்து மாறுகின்றன — ஓர் எண்ணிக்கையைச் சார்ந்திருப்பதற்கு முன் மீண்டும் சரிபார்க்கவும்.
- **ஓர் உள்ளீடு உண்மையில் எதற்கு உத்தரவாதம் அளிக்கிறது.** எந்த உள்ளீடும் வரிசை-வாரியான நம்பகத்தன்மை மதிப்பீட்டைக் கொண்டிருக்கவில்லை; API-யும் அவ்வாறான ஒன்றை வழங்குவதில்லை — மேலுள்ள ஒவ்வொரு எண்ணிக்கையையும் ஒரே மாதிரியான, வெளிப்படையாகக் குறிப்பிடப்படாத தரத்தைக் கொண்ட மதிப்பீடாகக் கருதவும். இரண்டு உண்மைகள் மட்டும் வேறுபட்டவை; ஏனெனில் அவை அனுமானிக்கப்படாமல் கைமுறையாகத் தொகுக்கப்பட்டவை: 44 உள்ளீடுகள் தனியாக ஆவணப்படுத்தப்பட்ட கடின நிறுத்தத்தைக் கொண்டுள்ளன (அவற்றில் 39 xKiro வரிசைகள்; அவை அனைத்தும் ஒரே தினசரி ஒதுக்கீட்டைப் பகிர்கின்றன), மேலும் 13 உள்ளீடுகள் prompt பயிற்சி குறித்த வெளிப்படுத்தலைக் கொண்டுள்ளன. இலவச ஒதுக்கீட்டை மீறினால் மறைமுகமாகக் கட்டணம் வசூலிக்கத் தொடங்காமல் கோரிக்கை மறுக்கப்படும் என்று வழங்குநரின் சொந்த விதிமுறைகள் கூறும்போது மட்டுமே `hardStopGuaranteed` அமைக்கப்படுகிறது; அதற்கான ஆதாரம் உள்ளீட்டிற்கு அடுத்துள்ள கருத்துரையில் இருக்கும். இது ஒருபோதும் இயல்புநிலையாக `true` என அமைக்கப்படுவதில்லை; யாரும் சரிபார்க்காத ஓர் உள்ளீட்டில் இது அமைக்கப்படாமலேயே இருக்கும். எனவே, hard-stop கொடி இல்லாதது "உறுதிப்படுத்தப்படவில்லை" என்பதையே குறிக்கும்; "கட்டணம் வசூலிக்கும் என்பது தெரியும்" என்பதைக் குறிக்காது. **STRICT பயன்முறை** (விருப்பத்தேர்வான `freeAccessPolicy=strict` வழிப்படுத்தல் தடுப்பு) இந்தக் கொடியைக் கொண்ட உள்ளீடுகளை மட்டுமே நம்புகிறது; மற்ற எல்லா இலவச அடுக்குகளும் `no-hard-stop` என விலக்கப்படுகின்றன (`open-sse/services/autoCombo/strictZeroCostFilter.ts`-ஐப் பார்க்கவும்). இந்தத் தடுப்பு ஒரு தொகுப்பை வடிகட்டும்போது, இயக்குநருக்குத் தெரியும் பதிவில் விலக்கப்பட்ட எண்ணிக்கையும் அதில் `no-hard-stop` வகையின் பங்கும் தெரிவிக்கப்படும்.
- `estMonthlyFreeTokens` = மீண்டும் மீண்டும் கிடைக்கும் மாதாந்திர tokens மட்டும். **ஒருமுறை மட்டுமே கிடைக்கும் பதிவுசெய்தல் credits மீண்டும் கிடைப்பதில்லை**, எனவே அவை 0 ஆகக் கணக்கிடப்படும். நிறுத்தப்பட்ட அடுக்குகளும் 0 ஆகும்.
- தினசரி token உச்சவரம்பு → `monthly = daily × 30`. RPD மட்டும் ஆவணப்படுத்தப்பட்டிருந்தால் → `RPD × ~800 output tokens × 30`. RPM/TPM மட்டும் இருந்தால் (தினசரி உச்சவரம்பு இல்லை) → **உச்சவரம்பற்றது** (கீழே பார்க்கவும்).
- **நிரந்தரமாக இலவசம், ஆனால் வெளியிடப்பட்ட token உச்சவரம்பு இல்லை** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): இவை விகிதம்/ஒருங்குநிகழ்வு கட்டுப்படுத்தப்பட்ட உண்மையான, மீண்டும் மீண்டும் கிடைக்கும் இலவச அணுகல்கள். இவற்றை `recurring-uncapped` என வகைப்படுத்தி, **ஒருபோதும் கூட்டுத்தொகையில் சேர்ப்பதில்லை** — `RPM × 24/7 × 30d` எனப் பெருக்குவது கற்பனையான உச்சவரம்பை உருவாக்கும் (நாங்கள் நிராகரிக்கும் மிகைப்படுத்தல் இதுவே). அவை இருப்பதை நீங்கள் அறிந்துகொள்ள அவை பட்டியலிடப்பட்டுள்ளன.
- **வைப்புத்தொகை மூலம் திறக்கப்படும் அதிகரிப்பு:** இலவச ஒதுக்கீட்டை நிரந்தரமாக உயர்த்தும், ஒருமுறை செலுத்தப்படும் சிறிய top-up (OpenRouter: $10 → 1000 req/day ≈ +24M/mo). இது தனி எண்ணிக்கையாக அறிவிக்கப்படுகிறது; நிலையான முதன்மை எண்ணிக்கையில் சேர்க்கப்படுவதில்லை.
- **தகுதி-கட்டுப்படுத்தப்பட்ட ஒதுக்கீடுகள்** (`eligibilityGate: "regional-identity"`): பிராந்தியத்துடன் பிணைக்கப்பட்ட அடையாளச் சரிபார்ப்புக்குப் பிறகு மட்டுமே திறக்கப்படும் உண்மையான, மீண்டும் மீண்டும் கிடைக்கும் ஒதுக்கீடு (தற்போது சீனப் பெருநிலப்பரப்பின் உண்மைப் பெயர் சரிபார்ப்பு). அதே pool-dedupe விதியைப் பயன்படுத்தி தனி எண்ணிக்கையாக (`gatedRecurringTokens`) கணக்கிடப்படுகிறது; நிலையான முதன்மை எண்ணிக்கையில் ஒருபோதும் சேர்க்கப்படுவதில்லை. செயல்முறை (`freeType`) மாறாததால், வழிப்படுத்தலும் மாறாது.
- **ஆதார வகுப்புகள்.** விதி: பட்டியலில் உள்ள ஓர் எண்ணிக்கை, அதற்கடுத்துள்ள `// evidence:` கருத்துரையில் தனது ஆதாரத்தை மேற்கோள் காட்டும் — `public-page` (யார் வேண்டுமானாலும் படிக்கக்கூடிய வழங்குநரின் பக்கம்), `api-public` (வழங்குநரின் அங்கீகரிப்புத் தேவையற்ற endpoint; எடுத்துக்காட்டாக router.bynara.id-இல் உள்ள NaraRouter-இன் பொது plans endpoint), அல்லது `console-verified <date> por <who>` (இந்த எண்ணிக்கை ஒரு கணக்கின் console-க்குள் மட்டுமே தெரியும்; அதை யார், எப்போது பார்த்தார்கள் என்பதையும், அந்த வரம்பு இருப்பதாகக் கூறும் பொதுப் பக்கத்தையும் கருத்துரை பதிவு செய்யும்). இன்றைய நிலை: 2026-09-02 அன்று மீண்டும் தணிக்கை செய்யப்பட்ட ஐந்து blocks இதைக் கொண்டுள்ளன (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); 2026-09-02 மறுதணிக்கைக்கு முந்தைய உள்ளீடுகள் மீண்டும் பரிசீலிக்கப்படும் வரை முந்தைய ஆய்வை மரபாகப் பெறுகின்றன; ஆதாரக் கருத்துரை இல்லாத எந்தவொரு **புதிய அல்லது மாற்றப்பட்ட** எண்ணிக்கையும் ஒரு bug. இன்று `mistral` மட்டுமே console-verified ஆகும்.

இந்தத் துறையில் உள்ள பெரும்பாலான "மாதத்திற்கான இலவச டோக்கன்கள்" எண்ணிக்கைகள், ஒவ்வொரு மாடலுக்குமான அளவுகளின் கூட்டுத்தொகையாகும். எங்களுடையது வேண்டுமென்றே அவ்வாறு கணக்கிடப்படவில்லை:

- **ஒவ்வொரு பகிரப்பட்ட தொகுப்பும் ஒருமுறை மட்டுமே கணக்கிடப்படுகிறது.** Mistral-இன் இலவசத் திட்டம், ஒரு நிறுவனத்திற்கு மாதம் ஒன்றுக்கு 1B அனுமதியைக் கொண்டது; அதை ஐந்து மாடல்களின் கீழ் பட்டியலிடுவதால் அது 5B ஆகாது. ஒவ்வொரு மாடலாகக் கூட்டினால், எங்கள் சொந்தப் பட்டியல் **~7.4B** எனக் காட்டும் (2026-09-03 அன்று மீண்டும் கணக்கிடப்பட்டது; இந்த எண்ணிக்கை CI-ஆல் கட்டுப்படுத்தப்படவில்லை — பட்டியல் மாறும் ஒவ்வொரு முறையும் இதை மீண்டும் அளவிடவும்) — தலைப்பில் **~1.47B** என்று குறிப்பிடப்பட்டுள்ளது, ஏனெனில் ஒவ்வொரு வழங்குநரிலும் உள்ள ஒரு கணக்கால் உண்மையில் செலவிடக்கூடிய அளவு அதுவே.
- **தினசரி உச்சவரம்புகள் மாற்றப்படுகின்றன; வீதங்கள் அல்ல.** ஆவணப்படுத்தப்பட்ட tokens/day உச்சவரம்பு `× 30` ஆகிறது; ஆவணப்படுத்தப்பட்ட requests/day உச்சவரம்பு `RPD × ~800 டோக்கன்கள் × 30` ஆகிறது; requests-per-minute மட்டுமே வெளியிடும் வழங்குநருக்கு மாதாந்திர எண்ணிக்கை **இல்லை**, மேலும் அது _உச்சவரம்பற்றது_ எனப் பட்டியலிடப்படுகிறது; ஒருபோதும் கூட்டுத்தொகையில் சேர்க்கப்படாது. ஒரு வீத வரம்பை 24/7 ஆல் பெருக்குவது, நாங்கள் ஏற்க மறுக்கும் எண்ணிக்கை ஊதிப்பெருக்கமாகும்.
- **பிராந்திய அடையாளச் சரிபார்ப்புக்குப் பின்னால் உள்ள ஒதுக்கீடுகள் தனியாகக் காட்டப்படுகின்றன** (`+~6M பிராந்திய அடையாளச் சரிபார்ப்புக்குப் பின்னால்`), ஏனெனில் பெரும்பாலான வாசகர்களால் அவற்றைப் பயன்படுத்த முடியாது.
- **பதிவுசெய்தல் கிரெடிட்கள் முதல் மாதத்திற்கு மட்டுமே** பொருந்தும்; அவை நிலையான எண்ணிக்கையுடன் ஒருபோதும் கலக்கப்படாமல், இரண்டாவது எண்ணிக்கையாகத் தெரிவிக்கப்படுகின்றன.
- **இந்த எண்ணிக்கை CI மூலம் அமல்படுத்தப்படுகிறது.** `npm run check:docs-counts`, பட்டியலிலிருந்து மொத்தங்களை மீண்டும் கணக்கிட்டு, இந்தக் கோப்பு, README அல்லது பட்ஜெட் அட்டை அவற்றிலிருந்து விலகும்போது build-ஐத் தோல்வியடையச் செய்கிறது.

## ToS கவனிப்பு அட்டவணை

> **ToS கொடி ஓர் ஆலோசனை மட்டுமே; routing gate அல்ல.** `tos` எனக் குறிக்கப்பட்ட வழங்குநர்கள் இயல்பாகவே routing மற்றும் combo/fallback-இல் தொடர்ந்து சேர்க்கப்படுகிறார்கள்; இந்தக் கொடி `/dashboard/free-tiers` மற்றும் `/api/free-tier/summary` ஆகியவற்றில் மட்டுமே காட்டப்படும். `excludeTosAvoid` query parameter சுருக்கக் காட்சியை மட்டுமே பாதிக்கிறது; உலகளாவிய routing-ஐ அல்ல. இந்தத் தீர்மானம் `open-sse/config/freeTierCatalog.ts`-இல் உள்ளது (தகவலுக்காக மட்டுமே; routing engines இதைப் படிப்பதில்லை).

> self-hosted, ஒற்றைப் பயனர் தனிப்பட்ட proxy-க்கான ஒவ்வொரு வழங்குநரின் விதிமுறைகள் குறித்த விரைவான பார்வை. `caution` = சரிபார்க்க வேண்டிய தனிப்பட்ட பயன்பாடு அல்லது proxy தொடர்பான பிரிவு; `ambiguous` = தெளிவற்றது; `ok` = வெளிப்படையாக அனுமதிக்கப்பட்டது. இது தகவலுக்காக மட்டுமே; சட்ட ஆலோசனை அல்ல — நீங்களே முடிவு செய்யுங்கள்.

### ⚠️ எச்சரிக்கை — சரிபார்க்க வேண்டிய தனிப்பட்ட பயன்பாடு / proxy பிரிவுகள் (16)
