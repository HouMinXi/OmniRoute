## Кратко — какой объём бесплатного инференса фактически агрегирует OmniRoute?

Эти показатели относятся к отдельным учётным записям сторонних сервисов и различным условиям участия в рамках каталога. OmniRoute не предоставляет этот бюджет: необходимо самостоятельно получить требуемые учётные записи или учётные данные, подключить подходящих провайдеров и соблюдать установленные ими ограничения. Фактически доступный объём может быть ниже, вплоть до нуля в новой установке без подходящего маршрута. Провайдеры с пометкой `tos: avoid` по умолчанию исключены из автоматической маршрутизации.

**Проверено 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) предлагает единовременный промокредит в размере $5, для получения которого требуется указать способ оплаты; срок его действия истекает через 30 дней. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) публикует ограничения частоты запросов по проектам, моделям и тарифам; он по-прежнему не входит в количественную оценку месячного объёма, указанную в заголовке.

| Показатель                                            | Токенов в месяц                      | Значение                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документированная регулярная квота (стабильная)**   | **~1.62B**                           | **Пулы** бесплатных тарифов (из каталога по моделям), каждый общий пул учитывается **один раз**. Актуальный источник данных для `/api/free-tier/summary` и страницы «Бюджет бесплатных тарифов» на панели управления. **Используйте это число.**                                                                                                                                       |
| **+ первый месяц с бонусами за регистрацию**          | **~2.22B**                           | Стабильная квота + единовременные бонусы за регистрацию (Z.AI 20M, DeepSeek 5M, …) с устранением дублирования по учётным записям. **Только первый месяц** — не возобновляется.                                                                                                                                                                                                         |
| **+ постоянно бесплатно, без опубликованного лимита** | _не поддаётся количественной оценке_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальный регулярный доступ, ограниченный частотой запросов или параллелизмом, **без лимита токенов, который можно было бы учесть**. Указываются в списке, но никогда не суммируются (подсчёт по формуле `RPM×24/7` привёл бы к завышению, которое мы отвергаем). |
| **+ увеличение после внесения депозита**              | **+~24M**                            | Единовременное пополнение OpenRouter на **$10** увеличивает его бесплатный пул с 50 до 1000 запросов в день. Указывается отдельно, чтобы никогда не завышать стабильный показатель.                                                                                                                                                                                                    |
| **+ доступ после региональной проверки личности**     | **+~6M**                             | `modelscope` (привязка Alibaba Cloud + подтверждение личности по правилам материкового Китая). Реальная регулярная квота, представленная как `gatedRecurringTokens` / `gatedProviders` и отображаемая на панели управления. Никогда не включается в основной показатель: +~6M после региональной проверки личности.                                                                    |
| Теоретический максимум (все лимиты запросов, 24/7)    | ~10B                                 | Сумма всех лимитов провайдеров, экстраполированная на непрерывное использование. **Не является гарантией** — не указывайте её в заголовке.                                                                                                                                                                                                                                             |

**Честный заголовок:** _OmniRoute агрегирует **~1.62B документированных бесплатных токенов в месяц** (до ~2.22B в первый месяц с учётом бонусов за регистрацию) в 34 пулах бесплатных тарифов — плюс множество постоянно бесплатных провайдеров без фиксированного лимита, — а сжатие RTK + Caveman (экономия токенов на 15–95%) позволяет использовать этот объём ещё эффективнее._

> **Почему показатель снизился с прежних ~1,94B.** Обновление от 2026-06-17 — это исправление ради достоверности, а не потеря: для `gemini` теперь устранено дублирование в пуле (ранее показатель был завышен из-за отдельного учёта каждого варианта Flash, 462M → 60M), лимит `cloudflare-ai` исправлен на реальные 10k нейронов в день (122M → 30M), `doubao` переклассифицирован как разовый бонус за регистрацию (а не возобновляемый), а закрытые уровни удалены (`chutes`/`phind`/`kluster` прекратили работу). Это частично компенсировано `llm7` (корректные 5M в день → 150M) и новыми бесплатными провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Дополнительно скорректировано до ~1,37B в v3.8.42:** `longcat` был переклассифицирован с возобновляемого гранта 150M в месяц на разовый бонус 10M за регистрацию после завершения бесплатного ознакомительного периода. Применено то же правило достоверности — ни один провайдер не был удалён по ошибке.
>
> **Обновлено 2026-08-26 после вывода Felo Web из эксплуатации:** Felo Web исключён, пока происхождение/лицензирование производного от GPL кода остаётся в статусе HOLD; на тот момент исходные данные содержали 38 ключей пулов. Количество пулов рассчитывается динамически и контролируется CI (`check:docs-counts` завершает сборку с ошибкой, если приведённые выше числа расходятся с `computeFreeModelTotals()`).
>
> **Повторно проверено 2026-09-02 по собственным страницам провайдеров** (источники: комментарии `// evidence:` рядом с каждой повторно проверенной записью в `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` больше не публикуют количество токенов (Google удалил бесплатную таблицу для отдельных моделей 2025-12-23; бесплатный план Ollama предоставляет «стартовые кредиты на использование») и теперь указаны как **безлимитные**, их значения никогда не суммируются (−80M); у `groq` есть пять лимитов в 200K TPD **на каждую модель** (по 6M, +15M), а три устаревших идентификатора удалены; у `nara` один пул на 7M в день (+60M, 210M). Значение 1B для `mistral` отображается только в консоли учётной записи — см. раздел _Классы доказательств_ в методологии.
>
> **Исправлено 2026-09-03 (#11773):** `cerebras` был переклассифицирован с возобновляемого гранта 30M в месяц (старый пробный план без карты с 1M токенов в день) на разовый бонус $5 за регистрацию, для которого требуется способ оплаты. Применено то же правило достоверности, что и для LongCat.
>
> **Плюс xKiro (2026-09-03):** новый пул `xkiro-free` (150M в месяц) добавляет 35-й ключ возобновляемого пула. Felo Web остаётся исключённым, пока происхождение/лицензирование производного от GPL кода сохраняет статус HOLD. Теперь исходные данные показывают **34 ключей возобновляемых пулов** и **~1,62B стабильно доступных токенов** — это динамически рассчитываемое число, контролируемое CI (`check:docs-counts` завершает сборку с ошибкой, если оно расходится с `computeFreeModelTotals()`).

Крупнейшие участники с **документально подтверждёнными** объёмами: `mistral` 1,00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (пять лимитов для отдельных моделей), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` исключён — его грант LongCat-2.0 на 10M является разовым бонусом за регистрацию с обязательной KYC-проверкой, а не возобновляемым ежемесячным бюджетом.)

> ⚠️ Теоретический предел (~10B) завышен из-за провайдеров только с ограничениями частоты запросов, но **без опубликованного лимита токенов** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), для которых показатели рассчитывались бы как `RPM/TPM × 24/7 × 30d` — это теоретический максимум, который не сможет стабильно использовать ни одна учётная запись. Они **исключены** из обоснованного показателя (и вместо этого приведены в строке «бесплатно навсегда, без лимита»). Именно такое завышение делает многомиллиардные заявления конкурентов ненадёжными.

## Обновление от 2026-06-17 — что изменилось с 2026-06-05

Весь каталог был обновлён по результатам веб-исследования с участием 50 агентов (официальная документация + новости за последние 7 дней, с проверкой в состязательном режиме). Основные изменения:

- **Удалены / нет бесплатного тарифа (2026):** `chutes` (бесплатный тариф закрыт в 2026-03), `phind` (компания прекратила работу в 2026-01), `kluster` (закрыт 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (бесплатный доступ к MiMo отозван 2026-05-24, промоакция Nemotron завершилась в 2026-06 — повторно проверено 2026-06-18), `aimlapi` (бесплатный тариф приостановлен — повторно проверено 2026-06-18), `yi` (Yi-Light выведен из эксплуатации, действует оплата по мере использования — повторно проверено 2026-06-18), `featherless-ai` (в настоящее время бесплатного тарифа нет), `chipotle` («Pepper AI» от Chipotle — реконструированный методом обратной разработки виджет чата Amelia на `amelia.chipotle.com`, к которому обращался провайдер, теперь возвращает 404 по всем маршрутам, включая корневой; бэкенд выведен из эксплуатации или перемещён, подтверждено 2026-09-15 — полностью удалён из каталога, #13131/#4037). `iflytek` / `sparkdesk` остаются в списке, но снабжены предупреждением об условиях использования (Spark Lite бесплатен; условия использования ограничивают применение в качестве прокси/ретранслятора).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` отключены 2026-06-01, а `2.5 Pro` исключён из бесплатного тарифа (2026-04); теперь бесплатный тариф включает **только семейство Flash** (2.5/3/3.1/3.5 Flash + Gemma). Теперь каталог **объединяет** семейство Flash в общий пул (ранее объём был завышен из-за отдельного подсчёта каждого варианта: 462M → 60M).
- **Исправленные показатели:** `cloudflare-ai` 122M → **30M** (фактически 10k Neurons/день), `doubao` переклассифицирован как разовый бонус за регистрацию (а не периодически возобновляемый), `llm7` 4M → **150M** (документированные 5M токенов/день), бесплатные эндпоинты `together` с суффиксом «-Free» закрыты → бонус $25 за регистрацию также удалён (требуется минимальная покупка на $5, бесплатного пробного периода нет), период Preview у `longcat` завершён, а модели Flash выведены из эксплуатации → осталась только **LongCat-2.0**, переклассифицированная как разовый бонус за регистрацию в размере **10M** токенов (требуется KYC, бонус не возобновляется).
- **Обнаружены новые бесплатные провайдеры:** ⭐ **Kilo Code** (`kilo-gateway` — меняющийся набор «Auto Free»: семейство NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 меняющихся бесплатных моделей для программирования), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash навсегда бесплатны + бонус 20M за регистрацию), а также Trinity Large Preview от `arcee-ai`.
- **Новые прозрачные категории тарифов** (см. раздел «Методология»): категория _навсегда бесплатных без установленного лимита_ (реальный возобновляемый доступ без лимита токенов, который можно было бы учесть) и _увеличение лимита после внесения депозита_ (OpenRouter: $10 → +24M/мес.); обе отображаются **отдельно**, поэтому никогда не завышают основной показатель.

## Исправления по Bytez и Nous от 2026-10-15

[Тарификация Bytez](https://docs.bytez.com/model-api/docs/billing) ограничивает открытые модели бесплатного тарифа моделями с 7B параметров. Записи для моделей с 70B и 72B параметров требуют разблокировки с помощью приобретённых кредитов и были удалены. Mistral-7B остаётся в категории `recurring-credit`: кредиты обновляются каждые четыре недели, однако оплата рассчитывается за каждую секунду инференса, а лимит токенов не опубликован. Значения счётчиков токенов установлены в ноль, чтобы обозначить неизвестный объём, вместо неподтверждённой оценки в 1M токенов; это не означает отсутствие бесплатных кредитов. Изменения Nous подробно описаны в примечании о провайдере ниже.

## Два режима — подсчёт и принятие решений

OmniRoute отвечает на вопрос «бесплатно ли это?» с помощью двух режимов, которые намеренно используют
разные источники:

| Режим                     | Источник истины                                                                                                                                                              | Области применения                                                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Подсчёт / отображение** | Итоговый каталог — поставляемая базовая версия, дополненная данными Radar (`getRadarCatalog`)                                                                                | Общие показатели бесплатного уровня, карточка бюджета, панели мониторинга                                                            |

## Методология и оговорки

- Числа представляют собой **оценки верхней границы**, основанные на документированных лимитах бесплатного уровня каждого провайдера по состоянию на **2026-06-17** и собранные посредством веб-исследования. Бесплатные уровни постоянно меняются — перепроверяйте данные, прежде чем полагаться на них.
- **Что в действительности подтверждает запись.** Ни одна запись не содержит индивидуальной оценки достоверности, и API её не предоставляет — рассматривайте каждое приведённое выше число как оценку одинакового, неуказанного качества. Два факта отличаются, поскольку они курируются вручную, а не выводятся автоматически: 44 записи содержат независимо задокументированный жёсткий предел (39 из них — строки xKiro, имеющие общий суточный лимит), а 13 записей содержат уведомление об использовании запросов для обучения. `hardStopGuaranteed` устанавливается только тогда, когда собственные условия провайдера указывают, что превышение бесплатного лимита приводит к отклонению запроса, а не к незаметному началу списания средств; источник приводится в комментарии рядом с записью. Это значение никогда не устанавливается в `true` по умолчанию, а у записи, которую никто не проверял, оно остаётся незаданным. Поэтому отсутствие флага жёсткого предела означает «не установлено», а не «известно, что начнётся списание средств». **Режим STRICT** (добровольно включаемое ограничение маршрутизации `freeAccessPolicy=strict`) доверяет только записям, содержащим этот флаг; любой другой бесплатный уровень исключается как `no-hard-stop` (см. `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Когда ограничение фильтрует пул, видимый оператору журнал сообщает как количество исключений, так и долю `no-hard-stop` среди них.
- `estMonthlyFreeTokens` = только ежемесячно возобновляемые токены. **Одноразовые бонусы за регистрацию не возобновляются** и учитываются как 0. Прекращённые уровни также учитываются как 0.
- Суточный лимит токенов → `monthly = daily × 30`. Если документирован только RPD → `RPD × ~800 выходных токенов × 30`. Если указаны только RPM/TPM (без суточного лимита) → **без ограничения** (см. ниже).
- **Постоянно бесплатно, но без опубликованного лимита токенов** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): это реальный возобновляемый бесплатный доступ, ограниченный частотой запросов или параллелизмом. Мы классифицируем такие предложения как `recurring-uncapped` и **никогда не суммируем их** — умножение `RPM × 24/7 × 30d` дало бы фантастический потолок (такое завышение мы отвергаем). Они перечислены, чтобы вы знали об их существовании.
- **Повышение после пополнения:** небольшое однократное пополнение, которое навсегда увеличивает бесплатную квоту (OpenRouter: $10 → 1000 запросов/день ≈ +24 млн/мес.). Указывается как отдельное значение и не включается в основной стабильный показатель.
- **Квоты с ограничением по критериям допуска** (`eligibilityGate: "regional-identity"`): реальная возобновляемая квота, которая становится доступна только после проверки личности, привязанной к региону (на сегодняшний день — проверка настоящего имени в материковом Китае). Учитывается с применением того же правила дедупликации пулов в отдельном показателе (`gatedRecurringTokens`) и никогда не включается в основной стабильный показатель. Режим (`freeType`) не меняется, поэтому маршрутизация остаётся прежней.
- **Классы доказательств.** Правило: число в каталоге сопровождается ссылкой на источник в комментарии `// evidence:` рядом с записью — `public-page` (страница провайдера, доступная всем), `api-public` (не требующая аутентификации конечная точка провайдера, например общедоступная конечная точка тарифов NaraRouter по адресу router.bynara.id) или `console-verified <date> por <who>` (значение видно только в консоли учётной записи; в комментарии указывается, кто и когда его видел, а также общедоступная страница, подтверждающая существование лимита). Текущее состояние: пять блоков, повторно проверенных 2026-09-02, содержат такой комментарий (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, появившиеся до повторной проверки 2026-09-02, наследуют результаты предыдущего исследования, пока их не изменят; любое **новое или изменённое** число без комментария с доказательством является ошибкой. На сегодняшний день только `mistral` имеет статус `console-verified`.

## Почему наше число меньше, чем у других агрегаторов

Большинство показателей «бесплатных токенов в месяц» в этой сфере представляют собой суммы значений, указанных для отдельных моделей. Наш показатель намеренно рассчитывается иначе:

- **Каждый общий пул учитывается один раз.** Бесплатный план Mistral предоставляет один лимит в 1 млрд токенов в месяц на организацию; указание этого лимита для пяти моделей не превращает его в 5 млрд. При суммировании по моделям наш собственный каталог показывал бы **~7,4 млрд** (пересчитано 2026-09-03; этот показатель не контролируется CI — пересчитывайте его при каждом изменении каталога), но в заголовке указано **~1,47 млрд**, поскольку именно столько фактически может использовать одна учётная запись у каждого провайдера.
- **Суточные лимиты пересчитываются, ограничения скорости — нет.** Документированный лимит токенов в день преобразуется через `× 30`; документированный лимит запросов в день — через `RPD × ~800 токенов × 30`; если провайдер публикует только число запросов в минуту, месячный показатель **не** рассчитывается, а лимит указывается как _неограниченный_ и никогда не включается в сумму. Умножение ограничения скорости на круглосуточное использование — это искусственное завышение, от которого мы отказываемся.
- **Квоты, доступные только после региональной проверки личности, указываются отдельно** (`+~6 млн после региональной проверки личности`), поскольку большинство читателей не может ими воспользоваться.
- **Стартовые кредиты действуют только в первый месяц** и указываются отдельным показателем, не смешиваясь с постоянным значением.
- **Показатель контролируется CI.** `npm run check:docs-counts` пересчитывает итоговые значения по каталогу и завершает сборку с ошибкой, если данные в этом файле, README или карточке бюджета перестают им соответствовать.

## Что изменилось по сравнению с опубликованным каталогом (`freeNote`)

> Строки `freeNote` времён v3.8.0 устарели. Исправления, выявленные в ходе этого исследования (они определяют обновление каталога в `_tasks/features-v3.8.12`):

- **`360ai`** — Поставляемая freeNote «Бесплатные модели 360 AI Brain» выглядит устаревшей. Сейчас доступ предоставляется только после подачи заявки и является платным. Возможно, основанием для этой формулировки послужили промо-токены периода запуска в 2023 году (100–250 млн единоразово)…
- **`agentrouter`** — В поставляемой freeNote указано: «$200 бесплатных кредитов при регистрации». ## Глоссарий

| Термин                      | Значение                                                                       |
| --------------------------- | ------------------------------------------------------------------------------ |
| **RPM / RPD / RPH**         | Запросы в минуту / день / час                                                  |
| **TPM / TPD**               | Токены в минуту / день                                                         |
| **Документированный лимит** | Провайдер публикует явный дневной/месячный лимит токенов (обоснованный бюджет) |
| **Теоретический максимум**  | `rate-limit × 24/7 × 30d` — максимум, а не предоставленный бюджет              |
| **Нейрон**                  | Единица вычислений Cloudflare (~1 выходной токен)                              |
