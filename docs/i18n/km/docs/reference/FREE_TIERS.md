## តារាងចំណុចគួរយកចិត្តទុកដាក់អំពី ToS

> **ទង់ ToS គឺជាការណែនាំ មិនមែនជាច្រកគ្រប់គ្រងការបញ្ជូនទេ។** តាមលំនាំដើម អ្នកផ្តល់សេវាដែលបានសម្គាល់ `tos` នៅតែត្រូវបានដាក់បញ្ចូលក្នុងការបញ្ជូន និង combo/fallback; ទង់នេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ ប៉ារ៉ាម៉ែត្រសំណួរ `excludeTosAvoid` ប៉ះពាល់តែទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនប៉ះពាល់ដល់ការបញ្ជូនសកលទេ។ សេចក្តីសម្រេចស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ព័ត៌មានប៉ុណ្ណោះ មិនត្រូវបានអានដោយម៉ាស៊ីនបញ្ជូនទេ)។

> ការអានដោយសង្ខេបអំពីលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវានីមួយៗ សម្រាប់ប្រូកស៊ីផ្ទាល់ខ្លួនដែលបង្ហោះដោយខ្លួនឯង និងមានអ្នកប្រើតែម្នាក់។ `caution` = មានខចែងអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន ឬប្រូកស៊ី ដែលគួរតែពិនិត្យ; `ambiguous` = មិនច្បាស់លាស់; `ok` = ត្រូវបានអនុញ្ញាតយ៉ាងច្បាស់។ សម្រាប់ជាព័ត៌មាន មិនមែនជាដំបូន្មានផ្លូវច្បាប់ទេ — អ្នកជាអ្នកសម្រេចចិត្ត។
