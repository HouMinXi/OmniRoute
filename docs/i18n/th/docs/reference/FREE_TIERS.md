> **แหล่งข้อมูลหลัก (แค็ตตาล็อก):** `open-sse/config/freeModelCatalog.ts` (งบประมาณต่อโมเดล โดยตัดรายการซ้ำในพูลแล้ว) ตัวเลขงบประมาณโทเค็นด้านล่างมาจากการค้นคว้าบนเว็บแบบเรียลไทม์และเป็นเพียง **ค่าประมาณ** — ดู[ระเบียบวิธีและข้อควรระวัง](#methodology--caveats)

## TL;DR — OmniRoute รวบรวมการอนุมานฟรีได้มากเพียงใดกันแน่?

ตัวเลขเหล่านี้อธิบายบัญชีบุคคลที่สามและเงื่อนไขการมีสิทธิ์ที่แยกจากกันทั่วทั้งแค็ตตาล็อก OmniRoute ไม่ได้เป็นผู้มอบงบประมาณนี้: คุณต้องมีบัญชีหรือข้อมูลประจำตัวที่จำเป็น เชื่อมต่อผู้ให้บริการที่มีสิทธิ์ และปฏิบัติตามขีดจำกัดของผู้ให้บริการเหล่านั้น ความจุที่ใช้งานได้จริงอาจต่ำกว่านี้ รวมถึงอาจเป็นศูนย์สำหรับการติดตั้งใหม่ที่ยังไม่มีเส้นทางที่มีสิทธิ์ ผู้ให้บริการที่ทำเครื่องหมาย `tos: avoid` จะถูกยกเว้นจากการกำหนดเส้นทางอัตโนมัติโดยค่าเริ่มต้น

**ตรวจสอบเมื่อ 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) มอบเครดิตส่งเสริมการขายแบบครั้งเดียว $5 ซึ่งต้องใช้วิธีการชำระเงินและจะหมดอายุหลังจาก 30 วัน [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) เผยแพร่ขีดจำกัดอัตราตามโปรเจกต์/โมเดล/ระดับ โดยยังคงไม่นำมารวมในตัวเลขสรุปรายเดือนที่ระบุเป็นปริมาณ

**ตัวเลขสรุปที่ตรงไปตรงมา:** _OmniRoute รวบรวม **โทเค็นฟรีที่มีเอกสารกำกับ ~1.62B ต่อเดือน** (สูงสุด ~2.22B ในเดือนแรกเมื่อรวมเครดิตสมัครใช้งาน) จากพูลแพ็กเกจฟรี 34 พูล — พร้อมด้วยผู้ให้บริการฟรีถาวรที่ไม่มีเพดานอีกเป็นจำนวนมาก — และการบีบอัดด้วย RTK + Caveman (ประหยัดโทเค็น 15–95%) ช่วยให้ใช้งานได้มากยิ่งขึ้น_

> **เหตุผลที่ตัวเลขนี้ลดลงจาก ~1.94B ก่อนหน้า** การรีเฟรชเมื่อ 2026-06-17 เป็นการปรับแก้ให้ตรงกับความเป็นจริง ไม่ใช่การสูญเสีย: ขณะนี้ `gemini` ถูกหักรายการซ้ำในระดับพูลแล้ว (ก่อนหน้านี้ตัวเลขสูงเกินจริงเพราะนับ Flash แต่ละรุ่นแยกกัน จาก 462M → 60M), `cloudflare-ai` ถูกแก้ไขให้ตรงกับโควตาจริงที่ 10k-Neurons/วัน (122M → 30M), `doubao` ถูกจัดประเภทใหม่เป็นเครดิตสมัครใช้งานครั้งเดียว (ไม่ใช่โควตาที่เกิดซ้ำ) และนำระดับบริการที่ปิดตัวแล้วออก (`chutes`/`phind`/`kluster` ยุติให้บริการ) โดยมีการชดเชยบางส่วนจาก `llm7` (ตัวเลขที่ถูกต้องคือ 5M/วัน → 150M) และผู้ให้บริการฟรีรายใหม่ (Kilo, OpenCode Zen, Z.AI GLM-Flash)
>
> **ปรับแก้เพิ่มเติมเป็น ~1.37B ใน v3.8.42:** `longcat` ถูกจัดประเภทใหม่จากสิทธิ์แบบเกิดซ้ำ 150M/เดือน เป็นเครดิตสมัครใช้งานครั้งเดียว 10M หลังจากช่วงทดลองใช้ฟรีสิ้นสุดลง ใช้หลักความซื่อตรงเดียวกัน — ไม่มีผู้ให้บริการรายใดถูกนำออกโดยผิดพลาด
>
> **อัปเดตเมื่อ 2026-08-26 หลังจากยุติ Felo Web:** Felo Web ถูกตัดออก ขณะที่ที่มา/การอนุญาตใช้สิทธิ์ซึ่งสืบเนื่องจาก GPL ยังคงอยู่ในสถานะ HOLD; ณ เวลานั้นซอร์สรายงานคีย์พูล 38 รายการ จำนวนพูลเป็นข้อมูลสดและถูกตรวจสอบโดย CI (`check:docs-counts` จะทำให้บิลด์ล้มเหลว หากตัวเลขด้านบนคลาดเคลื่อนจาก `computeFreeModelTotals()`)
>
> **ตรวจสอบซ้ำเมื่อ 2026-09-02 โดยเทียบกับหน้าเว็บของผู้ให้บริการเอง** (แหล่งข้อมูล: ความคิดเห็น `// หลักฐาน:` ข้างแต่ละรายการที่ตรวจสอบซ้ำใน `open-sse/config/freeModelCatalog.data.ts`): `gemini` และ `ollama-cloud` ไม่เผยแพร่จำนวนโทเค็นอีกต่อไป (Google นำตารางโควตาฟรีรายโมเดลออกเมื่อ 2025-12-23; แผน Free ของ Ollama ระบุว่าเป็น "เครดิตการใช้งานเริ่มต้น") และขณะนี้ถูกระบุว่า **ไม่มีเพดาน** โดยจะไม่นำมารวมยอด (−80M); `groq` มีเพดาน **แยกตามโมเดล** จำนวนห้ารายการที่ 200K-TPD (รายการละ 6M, +15M) พร้อมนำ ID ที่ยุติแล้วสามรายการออก; `nara` เป็นบักเก็ตเดียวขนาด 7M/วัน (+60M, 210M) ส่วน 1B ของ `mistral` มองเห็นได้เฉพาะในคอนโซลบัญชี — ดู _ประเภทหลักฐาน_ ในส่วนระเบียบวิธี
>
> **แก้ไขเมื่อ 2026-09-03 (#11773):** `cerebras` ถูกจัดประเภทใหม่จากสิทธิ์แบบเกิดซ้ำ 30M/เดือน (ช่วงทดลองแบบเดิมที่ไม่ต้องใช้บัตร 1M โทเค็น/วัน) เป็นเครดิตสมัครใช้งานครั้งเดียวมูลค่า $5 ซึ่งต้องใช้วิธีการชำระเงิน ใช้หลักความซื่อตรงเดียวกับ LongCat
>

## สองระบอบ — การนับเทียบกับการตัดสินใจ

OmniRoute ตอบคำถามว่า "ใช้ฟรีหรือไม่?" ผ่านสองระบอบที่ตั้งใจอ่านข้อมูลจาก
แหล่งที่แตกต่างกัน:

| ระบอบ                  | แหล่งข้อมูลอ้างอิงหลัก                                                                                                                                                                 | ส่วนที่ใช้งาน                                                                                                                            |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **การนับ / การแสดงผล** | แค็ตตาล็อกที่ผ่านการประมวลผลแล้ว — ข้อมูลพื้นฐานที่มาพร้อมรีลีสและถูกซ้อนทับด้วยฟีด Radar (`getRadarCatalog`)                                                                          | ยอดรวมระดับฟรี การ์ดงบประมาณ แดชบอร์ด                                                                                                    |
| **การตัดสินใจ**        | เฉพาะแค็ตตาล็อกที่มาพร้อมรีลีส (`FREE_MODEL_BUDGETS` ใน `open-sse/config/freeModelCatalog.data.ts`) รวมถึงฮิวริสติกภายในเครื่อง (คำต่อท้าย `:free`, ราคาเป็นศูนย์, `grantsFreeAccess`) | ทุกส่วนที่ใช้ `src/shared/utils/freeModels.ts`: การนำเข้าโมเดล การกำหนดเส้นทาง `auto/*`, `GET /v1/models` และตัวอย่างแสดงผลในเบราว์เซอร์ |

การนับสามารถปรับปรุงได้ทุกครั้งที่มีฟีดพร้อมใช้งาน ส่วนการตัดสินใจยังคงอิงตาม
อาร์ติแฟกต์ของรีลีส ดังนั้นคำตอบจึงเหมือนกันทั้งในเบราว์เซอร์และบนเซิร์ฟเวอร์
สามารถทำซ้ำแบบออฟไลน์ได้ และทดสอบได้โดยไม่ต้องใช้ฐานข้อมูล หากปล่อยให้ตัวอย่าง
แสดงผลในเบราว์เซอร์อ่านจากแหล่งหนึ่ง ขณะที่การนำเข้าบนเซิร์ฟเวอร์อ่านจากอีกแหล่ง
จะทำให้ตัวอย่างแสดงผลไม่ตรงกับสิ่งที่เกิดขึ้นเมื่อคลิก — จึงจงใจคงการแบ่งนี้ไว้

## ระเบียบวิธีและข้อควรระวัง

- ตัวเลขเป็น **ค่าประมาณขอบเขตบน** จากขีดจำกัดระดับฟรีที่ผู้ให้บริการแต่ละรายจัดทำเอกสารไว้ ณ วันที่ **2026-06-17** ซึ่งรวบรวมจากการค้นคว้าบนเว็บ ระดับฟรีเปลี่ยนแปลงอยู่เสมอ — โปรดตรวจสอบซ้ำก่อนอ้างอิงตัวเลขใด
- **สิ่งที่แต่ละรายการรับรองจริงๆ** ไม่มีรายการใดมีการจัดระดับความเชื่อมั่นเป็นรายแถว และ API ก็ไม่ได้ให้ข้อมูลดังกล่าว — ให้ถือว่าตัวเลขทั้งหมดข้างต้นเป็นค่าประมาณที่มีคุณภาพระดับเดียวกันซึ่งไม่ได้ระบุไว้ มีข้อเท็จจริงสองประการที่แตกต่างออกไป เนื่องจากได้รับการดูแลจัดการด้วยมือแทนที่จะอนุมานขึ้นมา: 44 รายการมีการระบุจุดหยุดแบบตายตัวโดยอิสระ (39 รายการเป็นแถวของ xKiro ซึ่งทั้งหมดใช้โควตารายวันร่วมกันหนึ่งชุด) และ 13 รายการมีการเปิดเผยเกี่ยวกับการฝึกด้วยพรอมป์ `hardStopGuaranteed` จะถูกตั้งค่าก็ต่อเมื่อข้อกำหนดของผู้ให้บริการเองระบุว่า เมื่อใช้โควตาฟรีเกินกำหนด ระบบจะปฏิเสธคำขอแทนที่จะเริ่มเรียกเก็บเงินโดยไม่แจ้งให้ทราบ โดยมีแหล่งอ้างอิงอยู่ในความคิดเห็นข้างรายการนั้น ค่านี้จะไม่ถูกกำหนดเป็น `true` โดยปริยาย และรายการที่ยังไม่มีใครตรวจสอบจะยังคงไม่ถูกตั้งค่า ดังนั้น การไม่มีแฟล็กจุดหยุดแบบตายตัวจึงหมายถึง "ยังไม่ได้รับการยืนยัน" ไม่ใช่ "ทราบว่าจะเรียกเก็บเงิน" **โหมด STRICT** (กลไกป้องกันการกำหนดเส้นทาง `freeAccessPolicy=strict` ที่ต้องเลือกเปิดใช้) จะเชื่อถือเฉพาะรายการที่มีแฟล็กนี้เท่านั้น ระดับฟรีอื่นทั้งหมดจะถูกคัดออกด้วยเหตุผล `no-hard-stop` (ดู `open-sse/services/autoCombo/strictZeroCostFilter.ts`) เมื่อกลไกป้องกันกรองพูล บันทึกที่ผู้ปฏิบัติงานมองเห็นจะรายงานทั้งจำนวนรายการที่ถูกคัดออกและสัดส่วน `no-hard-stop`
- `estMonthlyFreeTokens` = เฉพาะโทเค็นรายเดือนที่เกิดซ้ำ **เครดิตฟรีสำหรับการสมัครครั้งแรกไม่เกิดซ้ำ** และนับเป็น 0 ระดับบริการที่ยุติให้บริการแล้วก็นับเป็น 0 เช่นกัน
- ขีดจำกัดโทเค็นรายวัน → `monthly = daily × 30` หากมีเอกสารระบุเฉพาะ RPD → `RPD × ~800 output tokens × 30` หากมีเฉพาะ RPM/TPM (ไม่มีขีดจำกัดรายวัน) → **ไม่จำกัดเพดาน** (ดูด้านล่าง)
- **ใช้ฟรีถาวร แต่ไม่มีการเผยแพร่ขีดจำกัดโทเค็น** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): บริการเหล่านี้ให้สิทธิ์ใช้งานฟรีแบบเกิดซ้ำจริง โดยจำกัดอัตรา/จำนวนการทำงานพร้อมกัน เราจัดประเภทเป็น `recurring-uncapped` และ **ไม่นำมารวมยอดเด็ดขาด** — การคูณ `RPM × 24/7 × 30d` จะสร้างเพดานในจินตนาการ (การทำให้ตัวเลขสูงเกินจริงซึ่งเราไม่ยอมรับ) รายการเหล่านี้ถูกแสดงไว้เพื่อให้คุณทราบว่ามีอยู่
- **การเพิ่มโควตาด้วยการฝากเงินเพื่อปลดล็อก:** การเติมเงินจำนวนเล็กน้อยแบบครั้งเดียวซึ่งเพิ่มโควตาฟรีอย่างถาวร (OpenRouter: $10 → 1000 คำขอ/วัน ≈ +24M/เดือน) รายงานเป็นตัวเลขแยกต่างหาก และไม่นำไปรวมในตัวเลขพาดหัวของโควตาคงที่
- **โควตาที่มีเงื่อนไขด้านคุณสมบัติ** (`eligibilityGate: "regional-identity"`): โควตาแบบเกิดซ้ำจริงที่เปิดใช้ได้หลังจากผ่านการตรวจสอบตัวตนซึ่งผูกกับภูมิภาคเท่านั้น (ปัจจุบันคือการยืนยันชื่อจริงในจีนแผ่นดินใหญ่) นับโดยใช้กฎการขจัดรายการซ้ำในพูลเดียวกันเป็นตัวเลขแยกต่างหาก (`gatedRecurringTokens`) และไม่นำไปรวมในตัวเลขพาดหัวของโควตาคงที่ ระบอบ (`freeType`) ยังคงเดิม ดังนั้นการกำหนดเส้นทางจึงไม่เปลี่ยนแปลง
- **ประเภทของหลักฐาน** กฎคือ ตัวเลขในแค็ตตาล็อกต้องอ้างอิงแหล่งที่มาในความคิดเห็น `// evidence:` ข้างรายการนั้น — `public-page` (หน้าของผู้ให้บริการที่ทุกคนอ่านได้), `api-public` (เอนด์พอยต์ของผู้ให้บริการที่ไม่ต้องยืนยันตัวตน เช่น เอนด์พอยต์แผนบริการสาธารณะของ NaraRouter ที่ router.bynara.id) หรือ `console-verified <date> por <who>` (ตัวเลขมองเห็นได้เฉพาะภายในคอนโซลบัญชี ความคิดเห็นจะบันทึกว่าใครเห็นข้อมูลนี้และเมื่อใด รวมถึงหน้าสาธารณะที่ระบุว่ามีขีดจำกัดดังกล่าว) สถานะปัจจุบันคือ บล็อกทั้งห้าที่ตรวจสอบซ้ำเมื่อ 2026-09-02 มีข้อมูลนี้ (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`) รายการที่มีอยู่ก่อนการตรวจสอบซ้ำเมื่อ 2026-09-02 จะสืบทอดงานวิจัยเดิมไปจนกว่าจะได้รับการแก้ไข ตัวเลข **ใหม่หรือมีการเปลี่ยนแปลง** ใดๆ ที่ไม่มีความคิดเห็นระบุหลักฐานถือเป็นข้อบกพร่อง ปัจจุบันมีเพียง `mistral` เท่านั้นที่ผ่านการตรวจสอบผ่านคอนโซล

## เหตุใดตัวเลขของเราจึงน้อยกว่าของผู้รวบรวมรายอื่น

ตัวเลข "โทเค็นฟรีต่อเดือน" ส่วนใหญ่ในพื้นที่นี้เป็นผลรวมของตัวเลขที่ระบุแยกตามโมเดล แต่ของเราตั้งใจไม่คำนวณเช่นนั้น:

- **แต่ละพูลที่ใช้ร่วมกันจะถูกนับเพียงครั้งเดียว** แผนฟรีของ Mistral มีโควตา 1B/เดือนหนึ่งชุดต่อองค์กร การแสดงโควตานี้ไว้ใต้ห้าโมเดลไม่ได้ทำให้กลายเป็น 5B หากรวมแยกตามโมเดล แค็ตตาล็อกของเราเองจะมีตัวเลข **~7.4B** (คำนวณใหม่เมื่อ 2026-09-03; ตัวเลขนี้ไม่ได้ถูกตรวจสอบโดย CI — ให้วัดใหม่ทุกครั้งที่แค็ตตาล็อกเปลี่ยนแปลง) — แต่ตัวเลขพาดหัวระบุ **~1.47B** เพราะนั่นคือจำนวนที่บัญชีหนึ่งบัญชีของผู้ให้บริการแต่ละรายสามารถใช้ได้จริง
- **ขีดจำกัดรายวันจะถูกแปลง แต่อัตราจะไม่ถูกแปลง** ขีดจำกัดโทเค็น/วันที่มีเอกสารกำกับจะคำนวณเป็น `× 30`; ขีดจำกัดคำขอ/วันที่มีเอกสารกำกับจะคำนวณเป็น `RPD × ~800 โทเค็น × 30`; ผู้ให้บริการที่เผยแพร่เฉพาะจำนวนคำขอต่อนาทีจะ **ไม่มี** ตัวเลขรายเดือนและจะแสดงเป็น _ไม่มีขีดจำกัด_ โดยจะไม่ถูกนำมารวม การคูณขีดจำกัดอัตราด้วยการใช้งานตลอด 24/7 คือการทำให้ตัวเลขสูงเกินจริงซึ่งเราปฏิเสธที่จะทำ
- **โควตาที่ต้องผ่านการตรวจสอบตัวตนตามภูมิภาคจะแสดงแยกต่างหาก** (`+~6M หลังการตรวจสอบตัวตนตามภูมิภาค`) เนื่องจากผู้อ่านส่วนใหญ่ไม่สามารถใช้โควตาเหล่านี้ได้
- **เครดิตสำหรับการสมัครใช้ได้เฉพาะเดือนแรก** และรายงานเป็นตัวเลขชุดที่สอง โดยจะไม่นำมารวมกับตัวเลขการใช้งานต่อเนื่อง
- **ตัวเลขนี้ถูกบังคับใช้โดย CI** `npm run check:docs-counts` จะคำนวณยอดรวมใหม่จากแค็ตตาล็อก และทำให้บิลด์ล้มเหลวเมื่อไฟล์นี้ README หรือการ์ดงบประมาณมีตัวเลขคลาดเคลื่อนไปจากผลรวมดังกล่าว
